# DecoArt Balloons — by Julia & Beata

Strona internetowa prezentująca usługi dekoracji balonowych (DecoArt Balloons) stworzona w HTML i CSS.  
Autorzy: Julia & Beata.

## Co jest w repozytorium
- `index.html` — główny plik strony
- `style.css` — styl strony
- `images/` — folder na zdjęcia i miniatury (umieść tam swoje pliki)
- `README.md` — ten plik

## Jak dodać zdjęcia i filmy z Facebooka
1. Jeśli posty/filmy są **publiczne**, można osadzić je bezpośrednio:
   - Film: użyj iframe z `https://www.facebook.com/plugins/video.php?href=LINK_DO_FILMU`
   - Post: użyj iframe z `https://www.facebook.com/plugins/post.php?href=LINK_DO_POSTU`
2. Jeśli materiały są prywatne lub chcesz mieć pełną kontrolę — pobierz obrazy i filmy i umieść w folderze `images/`, a następnie zamień w `index.html` ścieżki do plików.
